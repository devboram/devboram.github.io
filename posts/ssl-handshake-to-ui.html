SSL 실패를 사용자 안내 문구까지 배선하기

2026-08-31 network 7 min

앱을 켜자마자 "네트워크 연결을 확인해 주세요" 팝업이 뜬다는 제보를 받았다. 그런데 Wi-Fi 는 멀쩡했다. 로그를 까 보니 진짜 원인은 SSL 핸드셰이크 실패 — 기기 날짜가 틀어져 인증서 검증이 깨진 것이었다.

① 에러가 Boolean 으로 깎여 나가는 길

문제는 에러 매퍼가 HTTP 에러가 아닌 모든 실패를 "네트워크 연결 실패" 하나로 뭉개고 있었다는 점이다. 원인 정보가 실행기 → 설정 매니저 → 런치 화면을 지나며 Boolean 하나로 깎여 나갔다.

// KoApiExecutor.kt
is SSLHandshakeException ->
    KoApiResult.Error(code = HTTP_525)

② 정보가 화면까지 살아서 가는가

핵심은 예외를 삼키는 길목마다 이 질문을 던지는 것이다. 전용 코드 하나를 뚫어 두니 안내 문구가 "기기 날짜·시간을 확인해 주세요"로 바뀌었고, 문의가 재현 없이 종결됐다.
